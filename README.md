# Local-BIC refinement of candidate DAGs

This repository accompanies **“Local-BIC Refinement of Candidate DAGs: Exact and Greedy Selection with a Swine-Production Application.”** It implements model selection over every edge-deletion subgraph of a fixed candidate directed acyclic graph (DAG).

For a decomposable score, the fixed-candidate problem separates by child:

```text
min over G subset of G0 BIC(G)
  = sum over children j min over S subset of candidate parents(j) BIC_j(S).
```

The implementation therefore treats exact local best-subset selection as the primary method when the search finishes. It uses enumeration for moderate candidate indegrees, certified branch-and-bound for larger local problems, and clearly labels any resource-limited result as non-exact. Deterministic greedy deletion remains available as a fast approximation.

The commercial swine-production observations are proprietary and are not included. Only non-row-level derived summaries may be shared.

## Repository map

- `local_bic_refinement.py` — single source of truth for local BIC, exact enumeration, branch-and-bound, greedy refinement, pruning pressure, and graph metrics.
- `candidate_contamination_simulations.py` — central fixed-candidate experiments with false-positive, missing, reversed, weak, dense, high-indegree, and low-varsortability candidates.
- `reproduce_simulations.py` — NOTEARS candidate-generation experiments with exact and greedy refinement.
- `additional_noise_sensitivity.py` — Gaussian, centered-exponential, and unit-variance centered-Gumbel sensitivity analyses.
- `realdata_postselection_diagnostics.py` — authorized swine-data workflow, including exact-versus-greedy comparisons, indegrees, mortality diagnostics, effective-sample-size sensitivity, grouping-field audit, and explicitly segregated EBIC sensitivity.
- `simulation_diagnostics.py` — secondary mechanism, varsortability, and sample-size diagnostics.
- `make_manuscript_assets.py` — creates manuscript tables and vector figures directly from final CSV files and fails on numeric inconsistencies.
- `tests/test_local_bic_refinement.py` — algebra, invariance, optimality, failure-case, SHD, noise, and deterministic-seed tests.
- `REAL_DATA_SCHEMA.md` — construction notes for the 37 application variables.
- `results/` — shareable non-row-level outputs regenerated by the current code.

The retired HC-BIC and duplicate pruning implementations are not part of this repository.

## Exact and greedy algorithms

For child `j` with candidate parent set `P0j`, exact refinement minimizes

```text
BIC_j(S) = n log(RSS_j(S) / n) + (|S| + 1) log(n)
```

over every subset `S` of `P0j`. The union of the child-specific minimizers is the global BIC-minimizing subgraph of the candidate DAG. Enumeration is used by default through candidate indegree 15. Above that point, branch-and-bound uses a valid residual-sum-of-squares lower bound. A two-million-node default limit prevents an unfinished search from being mistaken for a proof: such results are returned as `hybrid-limited` with `globally_optimal=False`.

Greedy refinement begins with all candidate parents for a child, accepts the deletion with the largest current BIC decrease, and stops at a deletion-local endpoint. Accepted deletions strictly decrease global BIC, but greedy need not find the exact subset. The test suite contains a deterministic three-parent counterexample.

For a one-edge deletion,

```text
Delta BIC = n log(RSS_reduced / RSS_full) - log(n).
```

Equivalently, deletion improves BIC when the edge’s partial R-squared is below

```text
1 - n^(-1/n).
```

Conditional on a fixed candidate graph and the chosen information criterion, refinement has no additional user-selected tuning parameter. Exact and greedy selection are invariant to arbitrary nonzero variable rescaling conditional on that fixed candidate. This is not a scale-invariance claim for NOTEARS or any other upstream candidate learner.

## Central controlled experiment

Run the 12-setting, 100-replicate candidate-contamination experiment with:

```bash
python candidate_contamination_simulations.py \
  --replicates 100 --d 20 --n 500 \
  --out results/candidate_contamination
```

Every exact search must be certified. The outputs report:

- exact and greedy FDR, TPR, SHD, edge counts, and runtimes;
- greedy-minus-exact BIC gap and edge-set Jaccard similarity;
- frequency of greedy suboptimality with Wilson intervals;
- paired intervals for metric and BIC differences;
- candidate maximum indegree and total enumeration burden;
- initial pruning pressure versus actual deletion fraction, BIC improvement, and exact–greedy disagreement;
- path-based varsortability, including population-standardized heterogeneous-error settings near 0.5.

Structural Hamming distance is computed only by `graph_metrics()` in `local_bic_refinement.py`; a reversal counts as one operation.

## Unit-variance non-Gaussian sensitivity

```bash
python additional_noise_sensitivity.py \
  --simulation-replicates 20 \
  --out results/additional_noise_sensitivity
```

The Gumbel generator uses scale `sqrt(6)/pi` and subtracts `EulerGamma * sqrt(6)/pi`, giving mean zero and variance one. All methods use the canonical graph metrics and the same exact/greedy refinement implementations.

## Authorized swine-data analysis

Run the application only with an authorized local copy of `train2023cw_simple.csv`:

```bash
python realdata_postselection_diagnostics.py \
  --data C:/authorized/location/train2023cw_simple.csv \
  --out results/swine_application \
  --bootstrap 0 \
  --primary-only
```

The script does not export row-level records. It writes labeled adjacency matrices, edge summaries, complete candidate indegrees, local and global exact-versus-greedy comparisons, mortality-neighborhood evidence, illustrative effective-sample-size cutoffs, initial-pruning-pressure validation, collinearity diagnostics, and a source-file SHA-256 hash.

`Year_Quarter` is a four-level seasonal covariate, not a dated time index. The supplied analysis data contain no farm, site, batch, or defensible temporal-block identifier. The workflow therefore does not invent a block bootstrap or temporal constraint. Effective-sample-size results are explicitly labeled as sensitivity only, not cluster-corrected likelihood or inference.

The EBIC path is isolated in `greedy_ebic_sensitivity()` and is not part of the primary local-BIC method.

## Manuscript assets and numeric verification

After the final analyses finish, regenerate all manuscript tables and figures from the CSVs:

```bash
python make_manuscript_assets.py \
  --results results \
  --manuscript-root ../manuscript/NOTEARS_BP_JDS_Final_Source
```

The builder verifies replicate counts, exact-BIC dominance, summary frequencies, adjacency edge totals, refinement-subgraph relationships, and equality between summed local and global BIC gaps. It writes `manuscript_asset_manifest.json` with SHA-256 hashes and the values plotted in each figure.
