# Shareable derived results

This directory contains non-row-level outputs regenerated by the DAGGuard analysis code. The proprietary swine-production observations are not included.

## `candidate_contamination/`

The central 12-setting, 100-replicate fixed-candidate experiment, including candidate/DAGGuard graph metrics, exact-versus-greedy agreement, BIC gaps, pruning pressure, and deterministic run configuration.

## `additional_noise_sensitivity/`

End-to-end NOTEARS candidate experiments under Gaussian, centered exponential, and centered unit-variance Gumbel errors.

## `swine_application/`

Non-row-level outputs from the authorized commercial-swine workflow: labeled candidate/DAGGuard adjacency matrices, edge-refinement status, exact-versus-greedy comparisons, mortality diagnostics, and provenance including the source-data SHA-256 hash.

## `seven_method_benchmark/`

Audited summary results for the manuscript comparison of:

1. NOTEARS;
2. NOTEARS + DAGGuard-Greedy;
3. NOTEARS + DAGGuard-Exact;
4. the Wang et al. (2026) hybrid structural pipeline, transparently adapted to continuous inputs;
5. Li & Wang (2009) PC-FDR;
6. Strobl, Spirtes & Visweswaran (2019) PC-p;
7. ordinary PC.

The primary common endpoint is skeleton adjacency because PC-family methods need not return a uniquely oriented DAG. `simulation_primary_seven_methods.csv` contains the pooled skeleton comparison over the 240 common simulation datasets. `simulation_mean_replicate_metrics.csv` contains means of the replicate-level metrics. `realdata_primary_seven_methods.csv` and `realdata_mortality_neighborhood_support.csv` summarize the swine-data comparison. `method_implementation_provenance.csv` and `AUDIT_NOTES.md` document code provenance and adaptation choices.

## Conventions

- Directed DAG adjacency is `A[parent, child] = 1`.
- Structural Hamming distance counts a reversal as one operation for directed-DAG metrics.
- A DAGGuard refinement is called exact only when every child-specific search is certified.
- Greedy BIC gaps are `greedy minus exact` and are nonnegative up to numeric tolerance.
- The seven-method common table reports **pooled skeleton false-discovery proportion**, not a claim of nominal finite-sample FDR control.
