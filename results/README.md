# Shareable derived results

This directory contains non-row-level outputs regenerated by the current repository code. The proprietary swine-production observations are not included.

## `candidate_contamination/`

The central 12-setting, 100-replicate fixed-candidate experiment:

- `contamination_replicate_metrics.csv` — candidate, exact, and greedy replicate-level graph metrics and diagnostics.
- `contamination_method_summary.csv` — setting-by-method means.
- `exact_greedy_paired_summary.csv` — paired differences, 95% intervals, Wilson intervals for greedy suboptimality, BIC gaps, Jaccard agreement, and runtimes.
- `initial_pruning_pressure_validation.csv` — Pearson and Spearman associations with actual deletion fraction, BIC improvement, greedy gap, and edge disagreement.
- `contamination_run_config.json` — seeds, dimensions, settings, and SHD convention.
- `exact_greedy_contamination_comparison.pdf` and `.svg` — vector summaries generated from the paired CSV.

## `additional_noise_sensitivity/`

End-to-end NOTEARS candidate experiments under Gaussian, centered exponential, and centered unit-variance Gumbel errors:

- `additional_simulation_metrics.csv` — current-code replicate results for NOTEARS, exact refinement, greedy refinement, and standardized diagnostics.
- `additional_simulation_summary.csv` — method means.
- `pruning_diagnostics.csv` — false- and true-positive removals, candidate indegrees, greedy gaps, and agreement.
- `additional_simulation_run_config.json` — deterministic seeds and the Gumbel scale/centering specification.

## `swine_application/`

Non-row-level outputs from the authorized application workflow:

- labeled candidate, exact, and greedy adjacency matrices;
- candidate-edge refinement status and complete indegree distribution;
- child-specific and global exact-versus-greedy BIC comparisons;
- mortality-neighborhood and illustrative effective-sample-size diagnostics;
- initial-pruning-pressure validation;
- missingness, collinearity, binary-node, and grouping-field audits;
- a data-provenance summary with the source filename and SHA-256 hash but no observations;
- `application_run_config.json`, including the candidate settings, exact-search
  limits, Python/package versions, and source-data hash.

`Year_Quarter` is a four-level seasonal covariate and does not define a dated sequence. No farm/site/batch grouping field is present, so the repository reports neither a block bootstrap nor cluster-corrected inference.

## Conventions

- Directed adjacency is `A[parent, child] = 1`.
- Structural Hamming distance counts a reversal as one operation.
- A refinement is called exact only when every child-specific search is certified.
- Greedy BIC gaps are `greedy minus exact` and are therefore nonnegative up to numeric tolerance.
- Manuscript assets are generated from these CSVs; `manuscript_asset_manifest.json` in the source package records their hashes and plotted values.
